# 学習音声プレーヤー（v1.3.0）

講義の MP3 をスキマ時間に聞いて、**周回数・聴取時間・理解度をきっちり記録する**学習専用のプレーヤーです。
スマホの「ホーム画面に追加」で使います。一度取り込めば機内モードでも動きます。

**スマホで開く URL：https://ken811224-lgtm.github.io/study-audio-player/**
（GitHub Pages で公開。リポジトリ https://github.com/ken811224-lgtm/study-audio-player ）

### 直したあとに公開しなおす
1. `app.js` の `APP_VERSION`、`sw.js` の `CACHE`（例 `sap-v1.0.1`）、CHANGELOG を上げる
2. このフォルダで `git add -A` → `git commit -m "v1.0.1"` → `git push`
3. 1〜2 分で反映。スマホはアプリを 2 回開き直すと新しい版に入れかわる（記録と音声はそのまま）

## できること

| 場所 | 中身 |

### ファイル名の決まり（自動で分類）
「**科目＜コース＞番号 題名**.mp3」の形なら、取り込むだけで分かれます。

| ファイル名 | 科目 | コース | 番号 | 題名 |
|---|---|---|---|---|
| 不動産登記法＜基礎＞1 所有権に関する登記（1）.mp3 | 不動産登記法 | 基礎 | 1 | 1 所有権に関する登記（1） |
| 商業登記法＜応用＞12 役員変更.mp3 | 商業登記法 | 応用 | 12 | 12 役員変更 |

- ＜＞ のほか 【】〈〉《》[] でもかまいません。
- 番号は題名の頭の数字（「第3回」の 3 も可）。同じコースの中で 1 つでも数字がない・重なるときは、ファイル名の順に 1, 2, 3… と振ります。
- 「続けて再生」と周回マップは、同じ「科目＜コース＞」の番号順です。
- この形でないファイルは、取り込み欄に入れた科目名（空なら「未分類」）に入ります。

### Google ドライブから取り込む（v1.4.0）
iPhone のファイル選びの画面を使わずに、Drive の音声をアプリへ取り込めます（GAS の URL を設定に入れておく）。
1. PC で録った MP3 を、Google ドライブの **「034_講義録音」** フォルダに入れる（ブラウザで drive.google.com にドラッグ）
2. アプリの「一覧」→［☁ Drive から取り込む］
3. まだ取り込んでいないもの・録り直して新しくなったものに、最初からチェックが付いている→［選んだものを取り込む］
- 1 本ずつ受け取ってアプリにしまう（13MB で約 30 秒、35MB で約 1 分）。Wi-Fi のときに、画面を消さずに
- スマホのデータが消えたときも、このボタンで戻せる（記録は同期で戻る）
- 渡せるのはこのフォルダの中だけ。フォルダの名前を変えるときは gas/Code.gs の `DRIVE_FOLDERS`

### 録り直した音声に差し替える
記録（周回数・聴取時間・理解度）はそのままで、**音声だけ**入れ替えられます。続きの位置だけは最初に戻ります（長さが変わるため）。
- **同じ名前で取り込む**：前と同じファイル名（録り直しで付いた「_2」「_3」も同じとみなす）を［＋ MP3を取り込む］で選ぶと「音声だけ差し替えますか？」と聞かれるので［OK］。何本でもまとめてできます。
- **名前が違うとき**：その講義を再生中にして、カードの「音声を差し替える」から新しい MP3 を選ぶ。
- 同期に使う名前は前のままなので、ほかの端末の記録ともそのままつながります（ほかの端末の音声は、その端末で差し替えてください）。

### 記録の決まり
- **聴取時間**は「実際に再生が進んだ分」だけを数えます。シークで飛ばした分・止めている間は入りません。
  - 実時間＝かかった時間（2 倍速で 30 分の講義を聞けば 15 分）
  - 講義時間＝1 倍速に直した長さ（同じ例で 30 分）
- **周回 +1** は、再生位置が **90%** に届いたとき。ただし前の周回のあと**長さの半分以上を実際に聞いていること**（タイルを押して終わりのほうへ飛ばしただけでは数えません）。数え間違えたら［−1］［＋1］で直せます。
- **連続達成日数**は、目標（分）以上聞いた日が何日続いているか。今日まだ達していなければ昨日までで数えます。
- 記録はスマホの中（IndexedDB・localStorage）にすぐ保存。GAS を設定していれば、つながっているときにスプレッドシートと同期します（下の 4）。圏外ならためておき、つながった時・アプリを開いた時・1 分ごとにまとめて同期します。

## 1. パソコンで試す

```bash
cd C:\work\学習音声プレーヤー
python -m http.server 8765
```

ブラウザで http://localhost:8765/ を開きます（localhost ならオフラインの仕組みも動きます）。

## 2. スマホで使う（ホーム画面に追加）

スマホでオフラインの仕組み（Service Worker）が動くのは **https のサイト**だけです。家の Wi-Fi で `http://パソコンのIP:8765/` を開いても再生はできますが、機内モードで開けません。
次のどちらかで https に置くのがかんたんです（どちらも無料）。

- **Netlify Drop**：https://app.netlify.com/drop を開き、このフォルダ（`gas` と `README.md` 以外の index.html・style.css・app.js・sw.js・manifest.json・icons）をまとめてドラッグ → 出てきた https の URL をスマホで開く
- **GitHub Pages**：リポジトリにこのフォルダの中身を入れ、Settings → Pages で公開

置くのは画面の部品だけです。**MP3 はサイトに上げません**（スマホの中でファイルを選んで取り込みます）。

### iPhone（Safari）
1. Safari で URL を開く → 共有ボタン → 「ホーム画面に追加」
2. ホーム画面のアイコンから開く → ［＋ MP3を取り込む］→「ファイル」アプリから MP3 を複数選ぶ
   （MP3 は先に「ファイル」アプリの「このiPhone内」か iCloud Drive に入れておく）

### Android（Chrome）
1. Chrome で URL を開く → メニュー → 「ホーム画面に追加」（「アプリをインストール」）
2. アイコンから開く → ［＋ MP3を取り込む］→ MP3 を複数選ぶ

### 容量について
- 音声はアプリの中（IndexedDB）にコピーされます。取り込んだあと元の MP3 は消してもかまいません。
- 空き容量が少ないと途中で止まります。⚙ 設定の「保存した音声」で使っている量の目安が見られます。科目ごとに消せます。
- iPhone は、ホーム画面に追加せず Safari のまま使っていると、しばらく開かないとデータが消されることがあります。**必ずホーム画面から使ってください。**

## 3. 画面を消しても止まらないようにするコツ

- **iPhone**：ホーム画面のアイコンから開いて ▶ を押し、それから画面を消す。続けて次の音声へ進みます（同じ再生の部品を使い回しているため）。低電力モードでも基本は動きますが、止まるときは低電力モードを切る。古い iOS（14 以前）ではロック中の曲送りが止まることがあります。そのときは一度ロック画面の ▶ を押してください。
- **Android**：設定 → アプリ → Chrome（またはインストールしたアプリ）→ 電池 →「制限なし（最適化しない）」にする。省エネモード・「使っていないアプリを休止」も外す。
- **ヘッドセット（Shokz など）**：真ん中のボタン＝再生／一時停止。2 回押し・3 回押し（機種による）＝次／前。⚙ 設定の「ヘッドセット・ロック画面の前/次ボタン」を「10秒戻す／15秒進める」にすると、聞き逃したところをボタンで戻せます。
  - iPhone のロック画面は「前/次」と「10 秒戻し」のどちらか一方しか出せない決まりです（このアプリは前/次を出します）。

## 4. 端末どうしの同期・スプレッドシート（GAS）

スマホ・タブレット・パソコンなど**何台でも、同じ GAS の URL を入れるだけで記録がそろいます**。

| 記録 | そろえ方 |
|---|---|
| 周回数・聴取時間（単元ごと・日ごと） | 全部の端末の**合計**（2 台で 1 周ずつ聞けば 2 周） |
| 理解度 | いちばん**新しく変えた**端末のもの |
| 停止位置・「前回の続きから」 | いちばん**新しく聞いた**端末のもの（スマホで止めた続きをタブレットで聞ける） |
| 手で直した周回（±1） | その端末の分として合計に入る |

- 音声（MP3）は端末ごとに取り込みます。**ファイル名で照らし合わせる**ので、同じファイル名の MP3 を入れてください。
- 同期するのは、アプリを開いた時・画面に戻った時・聞いている間 1 分ごと・［今すぐ同期］を押した時です。
- ⚙ 設定の「この端末の名前」を入れておくと、スプレッドシートでどの端末で聞いたか分かります。
- 「音声と記録をすべて消す」をしても、スプレッドシートの記録は消えません（その端末は新しい端末として出直します）。

### GAS の準備

1. 新しい Google スプレッドシートを作る（名前は自由。例「学習音声の記録」）
2. 「拡張機能」→「Apps Script」→ もとからある中身を消して、`gas/Code.gs` の中身をすべて貼り付けて保存
3. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」→ 許可を求められたら自分のアカウントで許可
4. 出てきた「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）をコピー
5. アプリの ⚙ 設定 → 「GAS ウェブアプリの URL」に貼る →［保存する］→［今すぐ同期］
6. スプレッドシートに「再生ログ」「単元マスタ」「日別」「同期_単元」「同期_日別」のシートができていれば成功
7. ほかの端末でも 5 をする（URL は同じ、端末の名前だけ変える）

- **再生ログ**：一時停止・最後まで・周回 +1・理解度を変えた などのたびに 1 行（5 分以上続けて聞いているときは 5 分ごと）
- **単元マスタ**：ファイル名ごとに 1 行。全部の端末を合わせた 周回数・累積実時間・累積講義時間・最終聴取日・理解度・聞いた端末（同期のたびに作り直す）
- **日別**：全部の端末を合わせた日ごとの実聴取時間・講義時間（同期のたびに作り直す）
- **同期_単元・同期_日別**：同期の元になる端末ごとの数字。**手で直さないでください**
- 同じログが 2 回届いても 1 回しか入りません。
- Code.gs を直したときは「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→ デプロイ（URL は変わりません）。

## 5. バックアップ・機種変更

- ⚙ 設定 →「単元の記録 CSV を保存／コピー」「日別の記録 CSV を保存／コピー」（Excel で開けます）
- 機種変更：GAS の同期を使っていれば、新しいスマホで MP3 を取り込んで同じ URL を入れるだけで記録が戻ります。
- GAS を使っていないとき：古いスマホで「履歴を丸ごと保存（JSON）」→ 新しいスマホで同じ科目名で MP3 を取り込む →「履歴を読み込む」。周回数・理解度・停止位置・日別の記録が戻ります（音声そのものは入っていません）。
