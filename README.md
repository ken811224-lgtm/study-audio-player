# 学習音声プレーヤー（v1.0.0）

講義の MP3 をスキマ時間に聞いて、**周回数・聴取時間・理解度をきっちり記録する**学習専用のプレーヤーです。
スマホの「ホーム画面に追加」で使います。一度取り込めば機内モードでも動きます。

## できること

| 場所 | 中身 |
|---|---|
| 上の緑のカード | 前回止めた音声・位置・何周目か・今日の聴取時間（実時間と 1 倍速の講義時間）・🔥連続達成日数・今日の目標ゲージ。**タップで続きから再生**（一時停止からの再開は 3 秒戻してから） |
| いま再生中 | 周回の［−1］［＋1］、理解度［未評価］［◎ 完璧］［△ もう一度］［× 要テキスト確認］、累計時間、この音声を削除 |
| 一覧 | 科目名を入れて［＋ MP3を取り込む］（何個でも。ファイル名の番号順に自動で並ぶ。第2回＜第10回、全角数字も OK）。科目・すべて／未聴取／復習マーク・番号順／再生回数が少ない順／ご無沙汰順で絞り込み。タップで再生 |
| 周回マップ | 全単元を番号タイルで。0 回グレー／1 回薄い青／2 回青／3 回以上ゴールド。タップで再生 |
| 継続記録 | 直近 90 日の草グラフ（0 分／1〜14 分／15〜29 分／30 分以上）。マスをタップでその日の時間。これまでの合計・平均・最長連続など |
| 下の操作バー | ⏮ ↺10 ▶ 15↻ ⏭、シークバー、速さ 1.0／1.3／1.5／1.8／2.0／2.2（声の高さはそのまま・選んだ速さは覚える） |
| ⚙ 設定 | 目標（初期 15 分）、取り込むときの科目名、続けて再生、ヘッドセットの前/次ボタンの役目、GAS の URL・合言葉、CSV 保存・コピー、履歴の丸ごと保存・読み込み、音声の削除 |

### 記録の決まり
- **聴取時間**は「実際に再生が進んだ分」だけを数えます。シークで飛ばした分・止めている間は入りません。
  - 実時間＝かかった時間（2 倍速で 30 分の講義を聞けば 15 分）
  - 講義時間＝1 倍速に直した長さ（同じ例で 30 分）
- **周回 +1** は、再生位置が **90%** に届いたとき。ただし前の周回のあと**長さの半分以上を実際に聞いていること**（タイルを押して終わりのほうへ飛ばしただけでは数えません）。数え間違えたら［−1］［＋1］で直せます。
- **連続達成日数**は、目標（分）以上聞いた日が何日続いているか。今日まだ達していなければ昨日までで数えます。
- 記録はスマホの中（IndexedDB・localStorage）にすぐ保存。GAS を設定していれば送信キューに入れて、つながっているときに送ります。圏外ならキューにためて、つながった時・アプリを開いた時・1 分ごとにまとめて送ります。

## 1. パソコンで試す

```bash
cd C:\work\学習音声プレーヤー
python -m http.server 8765
```

ブラウザで http://localhost:8765/ を開きます（localhost ならオフラインの仕組みも動きます）。

## 2. スマホで使う（ホーム画面に追加）

スマホでオフラインの仕組み（Service Worker）が動くのは **https のサイト**だけです。家の Wi-Fi で `http://パソコンのIP:8765/` を開いても再生はできますが、機内モードで開けません。
次のどちらかで https に置くのがかんたんです（どちらも無料）。

- **Netlify Drop**：https://app.netlify.com/drop を開き、このフォルダ（`gas` と `README.md` 以外の index.html・style.css・app.js・sw.js・manifest.json・icons）をまとめてドラッグ → 出てきた https の URL をスマホで開く
- **GitHub Pages**：リポジトリにこのフォルダの中身を入れ、Settings → Pages で公開

置くのは画面の部品だけです。**MP3 はサイトに上げません**（スマホの中でファイルを選んで取り込みます）。

### iPhone（Safari）
1. Safari で URL を開く → 共有ボタン → 「ホーム画面に追加」
2. ホーム画面のアイコンから開く → 科目名を入れて［＋ MP3を取り込む］→「ファイル」アプリから MP3 を複数選ぶ
   （MP3 は先に「ファイル」アプリの「このiPhone内」か iCloud Drive に入れておく）

### Android（Chrome）
1. Chrome で URL を開く → メニュー → 「ホーム画面に追加」（「アプリをインストール」）
2. アイコンから開く → 科目名を入れて［＋ MP3を取り込む］→ MP3 を複数選ぶ

### 容量について
- 音声はアプリの中（IndexedDB）にコピーされます。取り込んだあと元の MP3 は消してもかまいません。
- 空き容量が少ないと途中で止まります。⚙ 設定の「保存した音声」で使っている量の目安が見られます。科目ごとに消せます。
- iPhone は、ホーム画面に追加せず Safari のまま使っていると、しばらく開かないとデータが消されることがあります。**必ずホーム画面から使ってください。**

## 3. 画面を消しても止まらないようにするコツ

- **iPhone**：ホーム画面のアイコンから開いて ▶ を押し、それから画面を消す。続けて次の音声へ進みます（同じ再生の部品を使い回しているため）。低電力モードでも基本は動きますが、止まるときは低電力モードを切る。古い iOS（14 以前）ではロック中の曲送りが止まることがあります。そのときは一度ロック画面の ▶ を押してください。
- **Android**：設定 → アプリ → Chrome（またはインストールしたアプリ）→ 電池 →「制限なし（最適化しない）」にする。省エネモード・「使っていないアプリを休止」も外す。
- **ヘッドセット（Shokz など）**：真ん中のボタン＝再生／一時停止。2 回押し・3 回押し（機種による）＝次／前。⚙ 設定の「ヘッドセット・ロック画面の前/次ボタン」を「10秒戻す／15秒進める」にすると、聞き逃したところをボタンで戻せます。
  - iPhone のロック画面は「前/次」と「10 秒戻し」のどちらか一方しか出せない決まりです（このアプリは前/次を出します）。

## 4. Google スプレッドシートへ自動で送る（GAS）

1. 新しい Google スプレッドシートを作る（名前は自由。例「学習音声の記録」）
2. 「拡張機能」→「Apps Script」→ もとからある中身を消して、`gas/Code.gs` の中身をすべて貼り付けて保存
3. （おすすめ）先頭の `var SECRET = '';` に合言葉を入れる。例 `var SECRET = 'shiho2027';`
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」→ 許可を求められたら自分のアカウントで許可
5. 出てきた「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）をコピー
6. アプリの ⚙ 設定 → 「GAS ウェブアプリの URL」に貼る、合言葉も同じものを入れる →［保存する］→［今すぐ送る］
7. スプレッドシートに「再生ログ」「単元マスタ」「日別」のシートができていれば成功

- **再生ログ**：一時停止・最後まで・周回 +1・理解度を変えた などのたびに 1 行（5 分以上続けて聞いているときは 5 分ごと）
- **単元マスタ**：科目＋ファイル名ごとに 1 行。周回数・累積実時間・累積講義時間・最終聴取日・理解度をアプリの数字で上書き
- **日別**：日ごとの実聴取時間・講義時間（直近 3 日分を送るたびに上書き）
- 同じログが 2 回届いても 1 回しか入りません。
- Code.gs を直したときは「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→ デプロイ（URL は変わりません）。

## 5. バックアップ・機種変更

- ⚙ 設定 →「単元の記録 CSV を保存／コピー」「日別の記録 CSV を保存／コピー」（Excel で開けます）
- 機種変更：古いスマホで「履歴を丸ごと保存（JSON）」→ 新しいスマホで同じ科目名で MP3 を取り込む →「履歴を読み込む」。周回数・理解度・停止位置・日別の記録が戻ります（音声そのものは入っていません）。
